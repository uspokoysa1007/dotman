# dotman

Менеджер dotfiles на Go: профили конфигов, симлинки и шаблоны.

## Возможности (план)

- профили конфигов (по машине/окружению);
- команды: `init`, `install`, `update`, `list`, `status`;
- симлинки на dotfiles;
- шаблоны с подстановкой переменных ({{.Home}} и т.п.);
- diff между локальным файлом и хранилищем.

## Стек

- Язык: Go (стандартная библиотека)

## Сборка и запуск

```bash
go build -o bin/dotman .
./bin/dotman install
```
